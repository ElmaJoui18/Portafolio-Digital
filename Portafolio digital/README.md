# Portafolio Digital

Portafolio personal de Elma Joui: proyectos, habilidades, trayectoria y bitácora de desarrollo.

## Ver en línea

https://ElmaJoui18.github.io/portafolio-digital/

## Estructura

- `index.html` — página principal
- `project-1.html`, `project-2.html`, `project-3.html` — detalle de proyectos
- `css/style.css` — estilos y tema claro/oscuro
- `js/main.js` — interactividad, bitácora y tema
- `assets/` — imágenes y favicon

## Publicar en GitHub Pages

1. Crear el repositorio `portafolio-digital` en GitHub (público, sin README inicial).
2. Ejecutar: `git push -u origin main`
3. En GitHub: Settings → Pages → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)`.
4. Abrir la URL pública.
